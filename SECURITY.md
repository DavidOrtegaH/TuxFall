# Seguridad de TuxFall

Proyecto personal de David Ortega Hoyas, sin cuentas ni backend. No se aceptan contribuciones externas. Para comunicar un problema de seguridad, escribe en privado a davidortegahoyas@gmail.com con pasos para reproducirlo; evita publicar datos personales o credenciales. No se promete un plazo de respuesta.

La política de contenido se aplica mediante meta CSP, dentro de las capacidades de GitHub Pages. No hay scripts remotos ni dependencias de producción. El guardado del récord es opcional. Los datos locales pueden ser alterados por el propietario del navegador: el marcador no es una clasificación competitiva verificable.

La revisión previa a publicar y sus límites están en [docs/AUDIT-2026-11-13.md](docs/AUDIT-2026-11-13.md). Solo la versión publicada y la rama develop reciben correcciones del mantenedor; no se garantiza mantenimiento de copias antiguas o forks.
