## Límites del alojamiento y del alcance

GitHub Pages no ofrece configuración propia de cabeceras HTTP por archivo. La CSP meta no puede imponer frame-ancestors ni X-Frame-Options; no se simulan con etiquetas ineficaces. El sitio no maneja cuentas, pagos ni datos enviados a una API. HTTPS y cabeceras del host se verifican tras publicar. Para cabeceras adicionales haría falta otro alojamiento o proxy.

El robots.txt útil debe estar en la raíz del host, no en /TuxFall/robots.txt. Este repositorio de proyecto no controla esa raíz; se publica sitemap.xml en la subruta correcta. No se añade un robots.txt de efecto engañoso. La indexación depende del buscador, no se garantiza por añadir metadatos. Un único URL con idioma guardado no justifica hreflang a supuestas páginas inglesas inexistentes.

No hay dependencias npm de producción ni scripts externos. Revisión de entradas: solo SVG constantes de la aplicación se insertan como HTML; preferencias y puntuaciones no se interpolan en ese HTML. Búsqueda de patrones habituales de credenciales en archivos versionados de trabajo sin coincidencias; no sustituye a revisar la historia completa ni a detectar todos los tipos de secretos. No se ha realizado pentesting intrusivo del proveedor ni probado Safari/Firefox o dispositivos físicos.
